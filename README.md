# Notorious

A note-reading practice game for band students: name each note on the staff before you run out of misses.

Play it: https://twiese86.github.io/noteorious/

- Works on phones, tablets, computers and classroom smartboards. No sign-up and no accounts.
- Practice data stays on the device it was played on. Students can save their practice as a file to hand in to their teacher.
- The teacher report (bottom corner) is protected by a code the teacher picks on their own device.
